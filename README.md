🚑 AcunMedyaHospitalProject
Bu proje, hastane süreçlerini dijitalleştirerek doktor, hasta ve randevu yönetimini daha verimli hale getirmeyi amaçlamaktadır. Kullanıcı dostu bir Admin Paneli ile tüm işlemleri tek bir noktadan yönetmek mümkün!

🚀 Öne Çıkan Özellikler
🔹 Admin Paneli – Kolay kullanılabilir bir yönetim arayüzü 🖥️
🔹 Randevu Sistemi – Hastalar için hızlı ve pratik randevu oluşturma 🏥
🔹 Dinamik İçerik – Tüm veriler gerçek zamanlı olarak yönetiliyor 🔄
🔹 Şık & Modern Arayüz – Responsive tasarım için Bootstrap & CSS 🎨
🔹 Verimli Veri İşleme – Entity Framework ile optimize edilmiş veri yönetimi ⚙️

🛠️ Kullanılan Teknolojiler
💻 ASP.NET MVC – Güçlü ve modüler bir web uygulama mimarisi
📌 Entity Framework Core – ORM ile kolay veritabanı yönetimi
📊 Microsoft SQL Server – Yüksek performanslı veritabanı sistemi
🌍 HTML, CSS & Bootstrap – Esnek ve şık bir kullanıcı arayüzü
⚡ JavaScript – Dinamik ve etkileşimli sayfa deneyimi
🔍 LINQ – Hızlı ve okunabilir veri sorguları

🔧 Teknik Detaylar
📂 MVC Yapısı – Model, View ve Controller katmanlarıyla düzenli kod yapısı
📝 CRUD İşlemleri – Kayıt ekleme, güncelleme, silme ve listeleme işlemleri
📄 _Layout.cshtml – Sayfanın ortak bölümlerini yöneten şablon dosyası
📌 Partial Views – Tekrarlayan bileşenleri optimize eden yapı
🛠️ Google Maps Entegrasyonu – Hastane konumunu harita üzerinden görüntüleme 🌍
